# บันทึกรายจ่าย — PWA + APK

แอปบันทึกรายจ่ายที่ถ่ายรูปใบเสร็จหรือสลิปแล้วให้ AI กรอกให้ เก็บรูปลง Google Drive
และสรุปยอดบน Google Sheet ของคุณเอง โฟลเดอร์นี้คือ **หน้าจอของแอป** ส่วนหลังบ้านอยู่ใน Google Apps Script

```
docs/            ← ไฟล์เว็บที่ GitHub Pages เสิร์ฟ (นี่คือตัวแอป)
package.json     ← ใช้ตอน build APK
capacitor.config.json
.github/workflows/build-apk.yml
```

---

## 1. อัปโหลดขึ้น GitHub

1. สมัคร/ล็อกอิน [github.com](https://github.com) → **New repository**
2. ตั้งชื่อ `expense` → เลือก **Public** → **Create repository**
3. กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `docs` และ `.github`) เข้าไป → **Commit changes**

> ถ้าลาก `.github` ไม่ติด ให้ข้ามไปก่อน แล้วค่อยเพิ่มทีหลังตอนจะทำ APK

## 2. เปิด GitHub Pages

**Settings** → **Pages** → Source เลือก **Deploy from a branch**
→ Branch = `main` และโฟลเดอร์ = **`/docs`** → **Save**

รอสัก 1-2 นาที จะได้ URL หน้าตาแบบนี้

```
https://ชื่อคุณ.github.io/expense/
```

## 3. เปิด API ฝั่ง Google

ในโปรเจกต์ Apps Script (ไฟล์ `Code.gs` เวอร์ชันล่าสุด)

1. **การทำให้ใช้งานได้** → **การทำให้ใช้งานได้รายการใหม่** → ประเภท **เว็บแอป**
2. ตั้งค่า
   - ดำเนินการในฐานะ = **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง = **ทุกคน** ← ต้องเป็นอันนี้ ไม่งั้นแอปเรียกไม่ได้
3. กด **การทำให้ใช้งานได้** แล้วคัดลอก URL ที่ลงท้ายด้วย `/exec`
4. เลือกฟังก์ชัน **showPairingInfo** → กด **▶ เรียกใช้** → ดู **บันทึกการดำเนินการ**
   จะได้ API URL, รหัสเชื่อมต่อ และลิงก์เชื่อมต่ออัตโนมัติ

> เปิดเป็น "ทุกคน" ไม่ได้แปลว่าใครก็เข้าถึงข้อมูลได้ ทุกคำสั่งต้องแนบรหัสเชื่อมต่อ 32 ตัว
> ที่สคริปต์สุ่มขึ้นมาให้ ถ้ารหัสหลุดให้รันฟังก์ชัน `resetToken()` เพื่อเปลี่ยนใหม่

## 4. เชื่อมแอปเข้ากับ Sheet

เปิด URL ของ GitHub Pages บนมือถือ แล้วเลือกทางใดทางหนึ่ง

- **ทางลัด** — เปิดลิงก์เชื่อมต่ออัตโนมัติที่ `showPairingInfo()` พิมพ์ออกมา
  (เอา URL ของ Pages มาต่อหน้า `#s=...`) แอปจะเชื่อมให้เองทันที
- **กรอกเอง** — แอปจะเด้งกล่อง `CONNECT` ให้วาง API URL กับรหัสเชื่อมต่อ

## 5. ติดตั้งเป็นแอป

| เครื่อง | วิธีทำ |
|---|---|
| iPhone | เปิดใน **Safari** → ปุ่มแชร์ → **Add to Home Screen** |
| Android | เปิดใน **Chrome** → เมนู **⋮** → **ติดตั้งแอป** |

เปิดจากไอคอนจะเต็มจอ ไม่มีแถบ URL มีหน้า splash เหมือนแอปทั่วไป

## ทำไฟล์ APK (ทางเลือก — เฉพาะ Android)

ไม่ต้องลง Android Studio ให้ GitHub build ให้บนคลาวด์

1. แก้ `capacitor.config.json` บรรทัด `"url"` ให้เป็น URL ของ GitHub Pages ของคุณ
2. ไปแท็บ **Actions** ในรีโพ → เลือก **สร้างไฟล์ APK** → **Run workflow**
3. รอประมาณ 5 นาที → เปิด run ที่เสร็จแล้ว → ดาวน์โหลด **expense-quest-apk**
4. ส่งไฟล์ `app-debug.apk` เข้ามือถือ แล้วกดติดตั้ง (ต้องอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")

APK ตัวนี้เป็นเปลือกบาง ๆ ที่โหลดหน้าเว็บจาก GitHub Pages
เวลาแก้แอปจึงแค่อัปไฟล์ใน `docs/` ใหม่ ไม่ต้อง build APK ซ้ำ

> APK แบบ debug ติดตั้งได้เลยแต่ขึ้น Play Store ไม่ได้
> ถ้าจะขึ้นสโตร์ต้องเซ็นด้วย keystore ของตัวเองและเสียค่าลงทะเบียนนักพัฒนา $25 ครั้งเดียว

## เวลาแก้แอป

| แก้อะไร | ต้องทำอะไร |
|---|---|
| หน้าตา / โค้ดฝั่งแอป | แก้ `docs/index.html` แล้ว commit — ผู้ใช้ได้ของใหม่ตอนเปิดครั้งถัดไป |
| โค้ดฝั่ง Google | แก้ `Code.gs` แล้ว **จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชันใหม่** |
| ไอคอนแอป | เปลี่ยนไฟล์ใน `docs/icons/` |

## ข้อจำกัดที่ควรรู้

- แอปต้องต่อเน็ตถึงจะบันทึกได้ เพราะข้อมูลอยู่บน Google Sheet
  ถ้าเน็ตหลุด แอปยังเปิดได้แต่บันทึกไม่ได้
- ใครมีทั้ง URL และรหัสเชื่อมต่อก็ใช้ได้ ปฏิบัติกับรหัสเหมือนรหัสผ่าน
- บน iOS ต้องเปิดด้วย Safari เท่านั้นถึงจะติดตั้งเป็นแอปได้ Chrome บน iOS ทำไม่ได้
